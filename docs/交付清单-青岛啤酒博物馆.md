## 七、技术要点与避坑

1. **本机 homebrew ffmpeg 未编译 libass/freetype** → `subtitles` / `ass` / `drawtext` 三个文字滤镜全部不可用，无法直接烧字幕。
   **替代方案**：PIL 渲染透明字幕层 PNG，再用 `overlay` 滤镜叠加，版式控制反而更自由。
2. **竖屏版需要裁切**：素材为 16:9，转 9:16 时居中裁切（`crop=1216:2160`），已逐帧核对人物主体完整。横屏版原生 16:9，**不裁切、构图完整保留**。
3. **横屏字幕需放大**：竖屏 1080 宽用 52px 占 4.8%，横屏 1920 用 56px 只占 2.9%，手机上偏小。终版横屏用 76px（末句 86px）。
4. **码率**：首版 14.9Mbps / 112MB 偏大，按视频号 1080p 甜点重编至 **8Mbps / 58MB**。
5. **响度**：首版 BGM 压至 -23.9 LUFS 偏低，平台二次增益易削波，调整至 **-17.4 LUFS**。
