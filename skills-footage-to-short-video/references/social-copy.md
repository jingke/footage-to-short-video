# 社媒文案模板（公众号 + 小红书）

成片做完后，用「步骤 11」生成的静帧和封面，再按本模板写两套文案。两套**语气完全不同**，
不要同一段话改个标题就发两个平台。

---

## 一、公众号长文（深度 / 故事 / 温度）

读者是「订阅了你的人」，愿意读长一点、有叙事和情绪的内容。

### 标题公式（四选一或组合）
- **数字感**：`3 个被忽略的瞬间，藏着这座城市的温柔`
- **场景感**：`雨天的海岸线，比晴天更好看`
- **悬念感**：`我们追了一下午海风，只为这一帧`
- **情绪感**：`有些风景，只有慢下来才看得见`

### 正文结构
1. **开头钩子**（1 段）：用一个具体画面 / 感官细节把人拉进去，别上来就介绍。
2. **叙事主线**（3~5 段小标题）：直接复用成片字幕的叙事线（如「沿海 → 渔村 → 石巷 → 海滩 → 山门」），
   每段配 1 张抽帧静帧。把字幕里的【金色高亮词】当金句加粗。
3. **细节 / 知识点**（1 段）：旅行干货、避坑、拍摄机位，提升收藏价值。
4. **结尾升华 + 行动**：一句情绪收尾 + 引导「关注 / 在看 / 留言」。

### 排版建议
- 小标题用 `##`，段间空行；金句单独成段、字号加大或加色。
- 配图：头图用脚本生成的 `wechat_header.jpg`；正文插 3~5 张 `stills/still_XX.jpg`，
  图注一句话说明（如「红瓦渔村贴着海湾」）。
- 全文控制在 800~1500 字，手机阅读不累。

## 二、小红书笔记（口语 / 种草 / 清单 / emoji）

读者是「刷到的陌生人」，前 2 秒不抓人就划走。要短、密、有真实感。

### 标题（必带 emoji）
`📍青岛 | 雨天追海的隐藏路线，本地人都夸会玩`
`🌊 被这片海岸治愈了｜附机位+避坑`

### 正文结构
- 开头 1 句痛点 / 安利：「周末不知道去哪？这条海岸线我连刷三天。」
- 中间分点（每条前打 ✅/📌/⚠️）：路线、机位、时间、花费、避坑。
- 结尾互动：「你们城市有这种海边吗？评论区告诉我～」
- **话题标签 3~6 个**：`#青岛旅行 #海边打卡 #小众路线 #周末去哪儿 #治愈系风景`

### 配图布局（封面 + 9 图）
1. 首图：脚本生成的 `xhs_cover.jpg`（3:4，标题大字吸睛）——**决定点不点进来看**
2~4. 过程 / 大景（抽帧静帧，横竖皆可，保持色调统一）
5~7. 细节特写（礁石、红瓦、食物、路人）
8. 避坑 / 机位示意
9. 结尾打卡图 + 一句 slogan

## 三、语气差异对照

| 维度 | 公众号 | 小红书 |
|---|---|---|
| 人称 | 我们 / 你（温和） | 我 / 姐妹 / 宝子（亲昵） |
| 句子 | 完整、有铺垫 | 短、碎、emoji 分隔 |
| 目的 | 读完有收获、想关注 | 秒懂、想收藏/去同款 |
| 标题 | 含蓄有回味 | 直给利益点 + emoji |
| 配图文字 | 少，靠排版 | 多，封面就要写满卖点 |

---

## 四、从成片字幕提炼主题

成片的 `captions[]` 已经是一条叙事线，直接复用：
- 每段 `text` 的【金色词】= 现成金句 / 关键词，公众号加粗、小红书做标题或标签。
- 文案主线 = 字幕顺序排列；不必另起炉灶。
- 若 `cover.line1/line2` 已写好，可直接当两平台副标题的母本。

> 文案由 agent 按本模板写成 `.md` 文件（`wechat_article.md` / `xhs_post.md`），
> 配图由 `extract_stills.py` + `make_social_assets.py` 产出，三者一起放进交付目录。
