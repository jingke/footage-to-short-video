# 短视频平台规格参考

## 微信视频号

| 项目 | 参数 |
|---|---|
| 推荐画幅 | **竖屏 9:16 / 1080×1920**（信息流全屏，完播率最高） |
| 横屏 | 16:9 / 1920×1080（信息流上下留黑边，点击后全屏） |
| 帧率 | 30fps（素材 60fps 时降到 30，文件更小、平台兼容性更好） |
| 视频编码 | H.264 High@4.1 |
| 码率 | 1080p 甜点 **8 Mbps** |
| 音频编码 | AAC 128~192 kbps |
| 时长 | 短视频黄金区间 30~60 秒 |
| 封面 | 需手动设置，勿用自动截帧 |

## 抖音 / 小红书

规格基本一致（1080×1920 / H.264 / 30fps / 8Mbps）。
抖音对码率容忍度更高，可放宽到 10 Mbps。

## 关于画幅选择的取舍

| 方案 | 优点 | 代价 |
|---|---|---|
| 竖屏居中裁切 | 信息流全屏，完播率最高 | 两侧各裁掉一部分画面 |
| 横屏原画幅 | 构图完整 | 信息流里占屏小 |
| 竖屏 + 模糊补边 | 主体完整且占满竖屏 | 上下模糊区域观感略怪，处理耗时 |

**实践建议**：一次交付**两个版本**（竖屏发信息流，横屏留作公众号嵌入/朋友圈），
两者共用同一套时间轴与字幕文案，只需重切片段和重渲染，成本很低。

## 交付目录约定

```
<项目名>/
├── config.json            # 项目配置（时间轴、字幕、裁切、BGM）
├── master_silent.mp4      # 无音轨母版（换 BGM 时用它重混）
├── final.mp4              # 终版（已混 BGM）
├── cover.jpg              # 封面
├── seg/                   # 切好的片段
├── caps/                  # 透明字幕层 PNG
└── bgm/                   # BGM 候选
widescreen/                # 横屏版，同样结构，另开目录避免覆盖
```
